# Technical Writing

Templates and process for developer documentation. Pick the reference for the document type at hand and read **only** that file — each is self-contained.

| Writing a… | Read |
| --- | --- |
| Technical blog post | `references/blog-post.md` |
| Reference / feature documentation | `references/reference-doc.md` |
| Tutorial | `references/tutorial.md` |
| Architecture Decision Record (ADR) | `references/adr.md` |
| User guide | `references/user-guide.md` |
| Any long or high-stakes piece — process, style, pitfalls, quality checklist | `references/writing-process.md` |

The templates are skeletons, not straitjackets: drop sections that don't apply, but keep the ordering — _why_ before _how_.
